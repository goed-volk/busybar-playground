# Display Hardware Specifications

## Front Display (RGB LED Matrix)
- **Resolution**: **72 × 16 pixels**
- **Type**: Full-color RGB LED matrix
- **Pixel Pitch**: 2.2 mm
- **Refresh Rate**: 60 Hz maximum
- **Color Format**: 24-bit RGB + 8-bit Alpha (`#RRGGBBAA`)

## Back Display (OLED Screen)
- **Resolution**: **160 × 80 pixels**
- **Type**: Monochrome OLED display
- **Grayscale**: 16 grayscale levels
- **Controller IC**: SSD1320
- **Gamma Correction**: Note that **gamma 0.35** mentioned in community tools is an **emulator approximation only**, not an official hardware specification value.
