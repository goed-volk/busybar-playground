# Device Hardware Specifications

## Technical Overview

- **Microcontroller / SoC**: STM32U595RI (ARM Cortex-M33) + Silicon Labs SiWG917 (Wi-Fi 6 / BLE 5.4 co-processor).
- **Storage**: **8 GB eMMC** internal flash storage (`/ext/` mount point).
- **Battery**: 18650 Li-ion battery (3250 mAh capacity).
- **Connectivity**:
  - **USB**: USB-C connector providing power and CDC-ECM virtual Ethernet LAN interface (`10.0.4.20`).
  - **Wi-Fi**: **2.4 GHz only** (802.11 b/g/n/ax Wi-Fi 6). 5 GHz networks are **not supported**.
  - **Bluetooth**: Bluetooth Low Energy (BLE 5.4).
- **Physical Controls**: Top navigation dial and physical buttons (`up`, `down`, `ok`, `back`, `start`, `busy`, `custom`, `off`, `apps`, `settings`).
